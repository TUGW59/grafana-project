# BloomAtlas P1 — local candidate preview

Local preview only, not publication approved. Uses `api/src/preview.ts` and the existing API handler. Candidate/evidence/audit files stay outside Git. `scripts/etl/prepare_preview.py` verifies audit hashes and adds display attribution fields. `BLOOMATLAS_PREVIEW_DIR` contains private `preview.json` and World plugin `world-dist`. Compose requires UID/GID and `BLOOMATLAS_P1_PASSWORD`. Bindings: localhost 3300 and 18182. The installer checks and prepares these automatically. `candidateMode` selects the preview UI, leaving both demo modes intact. Filter options are read from ref C (`/v1/preview-options`); Grafana variables are hidden textboxes driven by the panel and sent to API through ref A. No Story navigation in this preview until the Story owner integrates the same dataset. Exact licenses, full taxonomy and publication review remain open. Do not commit the private dataset or password.
